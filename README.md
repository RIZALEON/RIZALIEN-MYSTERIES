# RIZALIEN MYSTERIES

Public dossier. Open for solution implementation.

This is not the app repo.
The machine lives in [PROJECTR](https://github.com/RIZALEON/PROJECTR) and [ya-aim](https://github.com/RIZALEON/ya-aim).
This repo is the **mystery layer**: artifacts, ciphers, historical seams, and proposed implementations.

## How the public works a seal

1. Pick an open issue tagged `seal`.
2. File a **Solution** issue or a PR that adds a file under `solutions/<seal-id>/`.
3. A valid solution has four parts:
   - **Artifact** — what was observed (post, image, name, number, place)
   - **Ground** — what is historically or technically checkable
   - **Hypothesis** — the decode
   - **Implementation** — a concrete next action (text, map, code, exhibit, lesson, tool)
4. Maintainers mark seals `open` / `contested` / `sealed`.

Do not submit private keys, Essence files, passwords, or personal vaults.
